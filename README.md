# Между делами

Минималистичный журнал для interstitial journaling: отмечай начало и конец дел, а между ними записывай, как ты.

- Таймер текущего дела и паузы между делами
- Записи о состоянии — свободным текстом, привязываются к текущему делу
- Хроника и обзор дня, быстрый старт недавних дел
- Экспорт всех записей в .txt, резервная копия и восстановление (.json)
- Устанавливается на главный экран, работает без интернета

Все данные хранятся только в браузере на твоём устройстве.

## Публикация на GitHub Pages

1. Создай новый репозиторий на github.com (например, `mezhdu-delami`), можно публичный.
2. На странице репозитория: **Add file → Upload files**, перетащи все файлы из этой папки (включая `.nojekyll`), нажми **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<твой-логин>.github.io/mezhdu-delami/`.

Обновить приложение — загрузи новый `index.html` поверх старого тем же способом.
